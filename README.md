## 📲 ইনস্টল করার নিয়ম

1. APK ফাইলটা ডাউনলোড করো (~137 MB)
2. ফোনে **Settings → Security → Install unknown apps** এ গিয়ে তোমার ব্রাউজার/ফাইল ম্যানেজারের পারমিশন অন করো
3. APK ফাইলে ট্যাপ করো → **Install** চাপো
4. অ্যাপ খুলে Wi-Fi-তে AI মডেল ডাউনলোড করো — ব্যস! 🎉

> পুরনো ভার্সন (v1.8.x / v1.9.0) থাকলে ওপরে নতুনটা ইনস্টল করলেই হবে — ডেটা মুছবে না।
