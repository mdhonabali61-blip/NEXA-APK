## 📲 ইনস্টল করার নিয়ম

1. ওপরের লিংক থেকে APK নামাও (~140 MB)
2. ফোনে **Settings → Security → Unknown Sources / Install unknown apps** চালু করো
3. APK-তে ট্যাপ করে **Install** চাপো (Android 7.0+)
4. অ্যাপ খোলো → নাম-ক্লাস দাও → AI মডেল ডাউনলোড (Wi-Fi) → পড়া শুরু! 🚀
